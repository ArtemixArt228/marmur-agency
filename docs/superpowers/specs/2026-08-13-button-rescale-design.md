# DsButton: драбина розмірів, наскрізна стрілка, паритет hover

Дата: 2026-08-13
Гілка: `feat/editorial-homepage`

## Проблема

`DsButton` завеликий. `lg` — 56px заввишки з 16px капсовим текстом і 32px
горизонтальними полями; на макеті це читається як плашка, а не як контрол.
Паралельно виявилось друге: у варіантів `quiet`, `inverse` і `ghost` наведення
виражене самою лише прозорістю, тобто «зміни кольору» там фактично немає.

## Рішення

### 1. Драбина висот

Рівний крок 8px, усе на сітці 4px. Вертикального padding немає — висоту тримає
`min-height`, тож однорядкова кнопка дорівнює висоті рівно, а не «принаймні».

| size | висота | padding  | шрифт             | tracking              | іконка | gap         |
| ---- | ------ | -------- | ----------------- | --------------------- | ------ | ----------- |
| `sm` | 32px   | `0 14px` | `--text-label-sm` | `--tracking-label-sm` | 12     | `--space-2` |
| `md` | 40px   | `0 20px` | `--text-label-sm` | `--tracking-label-sm` | 14     | `--space-2` |
| `lg` | 48px   | `0 28px` | `--text-label`    | `--tracking-label`    | 16     | `--space-3` |

Було 36 / 44 / 56 з padding `8px 18px` / `12px 24px` / `16px 32px` і фіксованою
іконкою 14px.

`md` свідомо злазить із `--touch-target` (44px), на якому сидять `DsInput`,
`DsQuantityStepper` і `DsIconButton`. Це ціна рівного кроку; компенсуємо там,
де кнопка стоїть в одному рядку з полем (див. §4).

`ghost` лишається поза драбиною — `min-height: auto`, `padding: 0 0 6px`. Це
підкреслений текст-контрол, а не плашка; від свого size він бере тільки розмір
шрифту та іконки.

### 2. Стрілка за замовчуванням

`iconRight?: string | false`, значення за замовчуванням `"arrow-right"`.
`false` — аварійний вихід, який поки ніде не вмикається: спершу дивимось живцем.

Рух — 3px, а не 2px як у `OverlayTile`, щоб збігалося з `TextLink`: кнопка теж
«текст + стрілка» в рядку, а не кут плитки.

```css
.ds-button__arrow {
  transition: transform var(--duration) var(--ease-standard);
}
.ds-button:hover:not(.ds-button--disabled) .ds-button__arrow {
  transform: translateX(3px);
}
```

### 3. Паритет hover-кольорів

| варіант     | було                   | стає                                                 |
| ----------- | ---------------------- | ---------------------------------------------------- |
| `primary`   | → `brand-dark`         | без змін                                             |
| `premium`   | → `brand-dark`         | без змін                                             |
| `secondary` | заливка `brand`        | без змін                                             |
| `quiet`     | тільки `border-strong` | інверсія: фон `foreground`, текст `background`       |
| `inverse`   | `opacity: .92`         | фон → прозорий, текст і рамка → `foreground-inverse` |
| `ghost`     | `opacity: .92`         | риска `border-strong` → `currentColor`               |

`--hover-opacity` зникає з кнопок повністю: колір несе всю роботу.

Риска `ghost` на ховері — саме `currentColor`, а не `--color-foreground`.
`HeroSplit` перефарбовує `.hero__ghost` в ivory для темного героя, і жорсткий
обсидіан у ховері дизайн-системи перебив би її специфічністю (0,4,0 проти
0,2,0), лишивши невидиму риску на темному тлі.

### 4. Місця виклику

- З шести файлів прибрати тепер зайвий `icon-right="arrow-right"`:
  `CartSlideover`, `home/WhatsNew`, `about`, `delivery`, `thanks`, `checkout`.
- `ProtoCta.noArrow` → `:icon-right="false"`.
- `DsFooter`: кнопка розсилки піднімається з `sm` до `md`. Початкове
  обґрунтування було хибне — я думав, що вона стоїть в одному рядку з
  `DsInput` і розрив по низу зросте до 12px. Насправді колонка розсилки
  вузька, `flex-wrap` спрацьовує вже на 1440px, і кнопка лягає **під** поле.
  Причина інша й лишається чинною: 32px зі стрілкою під 44px полем виглядають
  недоважено, `md` тримає вагу поля.
- Сторінка товару: `lg` (48px) поруч із `DsQuantityStepper` (44px), вирівняні
  по центру. 4px різниці лишаються навмисно — головний CTA має домінувати.
- `docs/design-system.md`: запис §17 у розділі відхилень.

## Поза межами

`prefers-reduced-motion` не чіпаємо: `base.css` уже глушить усі переходи
глобально.

Токени в `assets/css/design-system/` не редагуються — вони дзеркалять Claude
Design. Усі значення живуть у самому компоненті.
