# Marmúr — дизайн-система (імпорт)

Джерело: Claude Design → **Marmúr — Design System**
`https://claude.ai/design/p/7574ff5e-74c6-4a76-9b52-e07ca1c68613`

Токени в цій теці — дослівна копія `tokens/*.css` із того проєкту. Правити
значення тут не можна: змінюємо в Claude Design і переносимо сюди, інакше
код і дизайн-система розʼїдуться.

| Файл             | Що всередині                                                              |
| ---------------- | ------------------------------------------------------------------------- |
| `colors.css`     | 7 базових кольорів + семантичні ролі (§4, §5)                             |
| `typography.css` | Cormorant Garamond + DM Sans, шкала й композитні ролі (§7–§9)             |
| `spacing.css`    | 4→160 та вертикальний ритм секцій (§12)                                   |
| `layout.css`     | контейнер 1440, gutters, висота шапки, брейкпоїнти (§11)                  |
| `shape.css`      | радіуси 0–6px, hairline-рамки, дві тіні, співвідношення сторін (§24, §34) |
| `motion.css`     | 200–500ms, `cubic-bezier(.22,.61,.36,1)`, hover/press (§25, §26)          |
| `base.css`       | скидання й типографічна база документа                                    |
| `utilities.css`  | **єдиний файл не з Claude Design** — layout-класи з `ui_kits/website`     |

Шрифти підключені як `<link>` у `nuxt.config.ts` (Google Fonts), а не через
`@import` у CSS — щоб не робити водоспад запитів. Коли прийдуть ліцензовані
файли, замінюємо на self-hosted `@font-face`.

## Правила, які легко порушити

- Заокруглення лише 0–6px. `border-radius: 9999px` у системі не існує.
- Тіней немає. Виняток — `--shadow-overlay` і `--shadow-drawer`.
- Градієнтів немає. Виняток — `--color-scrim` над фотографією.
- Без емодзі, без декоративних іконок, без «картки з рамкою і тінню».
- Великі літери — лише малий сансовий шар (11–13px, tracking 0.14em).
- Анімації: без bounce, spring, parallax і нескінченних циклів.

## Компоненти

Порти на Vue живуть у `app/components/ds/` і повторюють API оригінальних
`.jsx` з Claude Design. Прикладні компоненти магазину (кошик, ціна зі
знижкою) — у `app/components/proto/`; вони збираються з `Ds*`.
